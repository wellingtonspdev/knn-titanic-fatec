# Instruções do projeto

- Use commits no padrão Conventional Commits.
- O único dataset aceito nesta atividade é `data/train.csv`, o `train.csv` da competição Titanic do Kaggle.
- Não substitua o dataset por fontes alternativas ou dados sintéticos.
- Execute o notebook a partir da raiz do repositório ou pela pasta `notebooks/`; os caminhos devem continuar relativos.
