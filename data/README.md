# Dados do Titanic

Os CSVs usados nesta atividade vêm da competição **Titanic — Machine Learning from Disaster**, no Kaggle:

https://www.kaggle.com/competitions/titanic/data

Após aceitar as regras da competição e baixar o pacote de dados, copie estes três arquivos, mantendo exatamente os nomes abaixo, para este diretório `data/`:

```text
data/train.csv
data/test.csv
data/gender_submission.csv
```

O `train.csv` é o único dataset usado nos experimentos A/B/C. O `test.csv` não contém `Survived` e serve apenas para gerar a submissão opcional. O `gender_submission.csv` é somente um exemplo de formato, não o gabarito do teste.

Os CSVs não fazem parte do repositório e são ignorados pelo Git. Este arquivo mantém o diretório e as instruções disponíveis para quem clonar o projeto.
